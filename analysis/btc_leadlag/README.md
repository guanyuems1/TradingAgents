# BTC 能否作为 HYPE / LIT / SOL 的先导指标？—— 日频 Lead-Lag 与 Alpha 实证

**问题**：以 BTC 为先导信号买入 HYPE、LIT（Lighter）、SOL，这些币的价格反应在时间上是否落后于 BTC（存在可利用的时间差）？该做法有没有 Alpha？

**研究日期**：2026-08-23 · 数据截至：**SOL/BTC/HYPE 全部到 2026-08-23**（HYPE 缺口已由用户提供的 CoinGecko 日线补全并拼接），LIT 仅稀疏锚点

> **2026-08-23 更新（补全 HYPE 日线后重跑）**：核心结论不变且更强——全样本 613 天里 BTC 对 HYPE 次日收益的相关为 **−0.000**、Granger p=0.97、控制同期腿后 t=0.21。但有**三处修正**，见 §0。

---

## 0. 补全日线后的三处修正

补上 2026-05-24 → 08-23 的 HYPE 真实日线后（181 天，与原 CM 面板有 87 天重叠可交叉验证），重跑全套检验。**主结论未变**，但三处次要结论必须更正：

| # | 原报告 | 修正后 | 原因 |
|---|---|---|---|
| 1 | BTC 大跌后 HYPE 短线反弹"边际显著"（+1d **+2.5%, t=2.5**；+3d +4.2%, t=2.2） | **不成立**：+1d **+0.5%, t=0.4**；+3d +0.9%, t=0.5 | 一半来自**口径**（换一个同样合理的 BTC 价格源，同期就掉到 +1.05%, t=0.91），一半来自新增 3 个月样本外数据 |
| 2 | HYPE 下行 β(1.06) > 上行 β(0.96) | **无一致不对称**（换口径后翻转为 1.13/0.91） | 该不对称随数据源翻转；SOL(1.06/1.39)、ETH(1.11/1.37) 的下行放大在同源数据中稳健，**只有 HYPE 这条不成立** |
| 3 | Granger btc→alt 在 lag1 边际显著（p=0.049） | **完全不显著**（p=0.97） | 同样是口径 + 样本外数据；且原本的显著方向就是负号（次日均值回归），非跟涨 |

**修正 1 的方法论含义**：一个真实可交易的效应，不应该因为把"BTC 当天跌了 3%"换一个同样合理的价格源来度量就从 t=2.5 掉到 t=0.9（事件日集合从 45 天变成 37 天）。**这种脆弱性本身就是它不真实的证据**。所以原报告里"唯一勉强显著的信号"现在也站不住了——结论变成：BTC 日线信号对这三个币**没有任何方向上可靠的 Alpha**。

修正后的完整结论见下方 TL;DR（已更新）。

## TL;DR

1. **日频及以上不存在"BTC 先动、山寨后补"的正向领先**。BTC 与 SOL/HYPE 是同日强联动（同日相关 SOL 0.78、HYPE 0.51、ETH 0.83），而 BTC 对次日山寨收益的相关为**零**（lag+1：SOL −0.07、HYPE **−0.000**，613 天）。Granger p=0.97；控制同期腿 btc[t+1] 后 btc[t] 的系数 t=0.21。等你在日线上看到 BTC 的信号时，山寨当天已经同步走完了。
2. **六条 BTC 信号规则没有一条跑赢买入持有**。HYPE 全样本（613 天）买入持有累计对数收益 +1.45，而最好的规则只有 +0.72；所有规则的年化 Alpha 的 t 值都落在 ±1.1 内，无一可与零区分。SOL 同构。
3. **连"逆向反弹"也不成立（补全数据后的修正）**：BTC 单日 −3% 之后 HYPE 未来 1 天仅 +0.5%（t=0.4）、3 天 +0.9%（t=0.5）。原报告里 t≈2.5 的结果换一个 BTC 价格源同期就掉到 t=0.9——**任何方向上都没有可靠信号**。
4. **2020-21 年确实存在的 2-3 日 / 1-2 周正向传导已经消失**。SOL 长样本（2020-04 起）中 lag 2-3 日相关 +0.05~+0.07（t≈2-3）、周频 lag+1 周 +0.17（t=3.1）均显著——但拆分子样本后全部集中在前半段（2020-2023），2024-26 年为零甚至反号。市场效率已把这个时间差抹掉。
5. **月度"轮动"故事不可靠、方向因资产而异**：过去 21 天 BTC 强 → 未来 21 天 HYPE 相对 BTC 跑赢（t=2.3）但 **SOL 同期反而显著跑输**（t=−3.2）。同一时期两个币方向相反，说明这不是"BTC 先导"规律，而是各自的叙事强弱。
6. **持有 SOL/ETH 获得的是放大且不对称的 Beta，不是 Alpha**：SOL 下行 Beta 1.39 > 上行 1.06，ETH 1.37 > 1.11——BTC 跌时跟得更狠、涨时跟得少（同源数据，口径稳健）。**HYPE 不在此列**：其不对称随口径翻转，无一致结论。
7. **HYPE 与 LIT 的主导因素是自身叙事而非 BTC**：HYPE 与 BTC 的 60 日相关在 0.33-0.73 间摆动、现值 0.52（BTC 只解释其方差的 ~26%），2026 年 6 月起在 BTC 下跌时因 ETF 叙事逆势上涨（彭博/CNBC 报道）；LIT 上线 8 个月内的各阶段与 BTC 幅度脱节甚至反号（2026-05→08：LIT +88% / BTC −15%）。用 BTC 择时这两个币，噪音远大于信号。
8. **真正的领先只存在于分钟级**，属于高频套利者；日线数据既测不到、人工也吃不到。

**一句话**：BTC 日线信号对这三个币没有"时间差"可赚，**追涨和抄底两个方向都没有 Alpha**。SOL/ETH 相对 BTC 提供的是不对称放大的 Beta；HYPE/LIT 则主要是个体叙事风险。

## 1. 数据与构建

受限环境下可用的两条独立数据通道，互为交叉验证：

| 面板 | 来源 | 品种与窗口 | 时间戳约定 |
|---|---|---|---|
| CM 面板 | [Coin Metrics community data](https://github.com/coinmetrics/data)（GitHub 镜像，更新至 2026-05-24） | BTC/ETH（PriceUSD，2019 起）；SOL/HYPE（CapMrktEstUSD 反推，SOL 2020-04 起、HYPE 2024-12-13 起）→ 2026-05-23 | 当日收盘（00:00 UTC 次日） |
| API 面板 | [`@fawazahmed0/currency-api`](https://www.npmjs.com/package/@fawazahmed0/currency-api) npm 每日快照（904 版，无缺口） | BTC/ETH/SOL，2024-03-02 → 2026-08-23 | ~00:00-02:00 UTC 同一快照 |
| HYPE 补全 | CoinGecko 日线（用户在无网络限制的机器上用 `fetch_hype_extension.py` 抓取） | HYPE，2026-02-25 → 2026-08-23（181 天，与 CM 面板重叠 87 天） | 与 API 面板同一日网格（实测定标） |
| LIT | Coin Metrics `lit_lighter` + 公开报价页锚点 | 仅 7 个日度价格（2026-05-18..24）+ 成交量史 + 6 个稀疏锚点 | — |

**关键数据工程结论**（`build_dataset.py` 有完整记录）：

- Coin Metrics 社区 CSV 只对 BTC/ETH 保留完整 `PriceUSD`；SOL/HYPE 只能用 `CapMrktEstUSD`。实证验证它等于**分段常数的流通量估计 × 当日收盘价**（BTC 隐含流通量恒为 19.87M、日变化 0.002%；HYPE 对已公布参考价的隐含流通量恒为 238.4M），因此其对数差分就是收盘价日收益——只在罕见的"流通量估计修订日"出现一次性跳变。检测并剔除了一个修订日（2025-08-28：−23.8% vs BTC +1.1%，无任何行情佐证，前一日 $51、三周后创新高）。
- npm 快照面板中 BTC 与 SOL 出自同一文件同一时刻，**配对内部时间一致**——这是 lead-lag 检验的前提（跨源配对会因固定时差伪造出领先性）。2025-12-06 一版汇率损坏，剔除。
- 跨源校验：BTC 日收益两源相关 0.91（快照采样抖动所致，同快照内为共同噪声，不产生虚假先后）；SOL 市值反推收益 vs 快照收益相关 0.92，与 BTC 跨源水平相同，说明反推无额外失真。
- **LIT 指 Lighter**（zk-rollup 永续 DEX 的代币，2025-12-30 TGE + 25% 空投），不是 Litentry（Coin Metrics 中另有 `lit`，价格 $0.066 量级）。Lighter 在两条通道中都没有完整日线，只能做描述性分析。

**HYPE 序列的拼接与时间戳定标**（补全数据到位后新增，`build_unified_hype()`）：

- CM 社区 CSV 存在一个**内部错位**：`CapMrktEstUSD[D]` 用的是 `ReferenceRateUSD[D+1]` 的价格（实测 mcap[D]/RefRate[D+1] 恒为 238.4M），BTC 的 `PriceUSD[D]` 同样等于 `ReferenceRateUSD[D+1]`。**两条腿错位方向一致，所以原 CM 配对本身没有偏移错误**；但要并入 API 网格，CM 收益需整体前移一天。
- 补全数据的网格用 87 天重叠窗口实测定标：`corr(ext[D], cm对齐[D]) = 0.994`；与 BTC 腿配对时 `ext[D] ↔ api_btc[D]` 同日相关 +0.51，而错配成 `api_btc[D+1]` 为 **−0.23**——**配错腿会凭空造出一天的领先**，这也是本文坚持"配对必须同网格"的原因。
- 拼接点 2026-02-26，重叠段相关 0.994，交接处无跳变（见 fig4 虚线标记）。

**配对原则**：BTC↔HYPE 用拼接序列 + API 面板 BTC（全样本 613 天到 08-23），BTC↔SOL 用 API 面板（同快照），长样本稳健性用 CM 面板，ETH 作对照。

## 2. 方法

对每个配对（日频对数收益）：同日相关与 Beta（HAC-t）→ ±7 日交叉相关 CCF（95% 置信带 ±1.96/√n）→ 双向 Granger 因果（lag 1-5）→ 预测回归 `alt(t+1) ~ btc(t) + alt(t)`（Newey-West）→ 事件研究（BTC ±2%/±3% 日后 1/2/3/5 天，剔除事件日）→ 六条可执行规则回测（信号在 t 日收盘已知、持有 t+1 日，0/10/20bps 换手成本，Alpha 用日度回归对买入持有取残差）→ 周频 CCF 与 21 天"轮动"回归 → 子样本拆半稳健性。

## 3. 结果

### 3.1 同日联动强，跨日领先为零

![每日交叉相关](figures/fig1_ccf_daily.png)

同日柱（HYPE +0.51 / SOL +0.78）一柱独大；**其余所有 lag 都贴在零附近或置信带内**。HYPE 的 lag+1 恰为 **−0.000**（n=613），Granger btc→alt 各阶 p=0.81~0.99，预测回归 btc(t) 系数 −0.004（t=−0.03）。SOL 的 lag+1 为 −0.07，Granger 边际显著的方向同样是**负号**（次日轻微均值回归，非跟涨）。反向（alt→btc）全不显著。

### 3.2 事件研究：次日起两个方向都归零

![事件研究](figures/fig2_event_study.png)

| 事件 | n（HYPE/SOL） | HYPE 同日 | HYPE +1d | HYPE +3d | SOL +3d |
|---|---|---|---|---|---|
| BTC > +3% | 50/91 | +5.9% | +0.3% (t=0.3) | −1.1% (t=−0.9) | −0.2% |
| BTC < −3% | 44/71 | −4.0% | +0.5% (t=0.4) | +0.9% (t=0.5) | +0.4% |

同日一列就是 Beta：事件当天已经跟完。次日起**两个方向都归零**。

原报告在此处曾给出"BTC 大跌后 HYPE +1d **+2.5%**（t=2.5）"。补全数据后该结果不成立，归因如下（三种口径，同一份 HYPE 数据）：

| 口径 | n | +1d | +3d |
|---|---|---|---|
| ① 原 CM 配对（至 05-23，已发布） | 45 | +2.53% (t=2.55) | +4.22% (t=2.22) |
| ② 换 BTC 源、限同期（至 05-23） | 37 | +1.05% (t=0.91) | +2.01% (t=0.95) |
| ③ 换 BTC 源、全样本（至 08-23） | 44 | +0.48% (t=0.44) | +0.92% (t=0.46) |

①→② 是**口径效应**（把"BTC 当天跌 3%"换一个同样合理的价格源来度量，事件日集合从 45 天变 37 天），②→③ 是新增 3 个月样本外数据。一个真实可交易的效应不该如此脆弱——**这种口径敏感性本身就说明它不是真信号**。

### 3.3 回测：所有追涨规则 ≤ 买入持有

![策略净值](figures/fig3_equity_curves.png)

HYPE（2024-12→2026-08 全样本 613 天，B&H 累计对数收益 **+1.45**）：

| 规则（信号→次日持仓） | 毛收益 | Sharpe | 年化 Alpha vs B&H | 净 10bps |
|---|---|---|---|---|
| BTC 上涨日后做多 | +0.72 | +0.62 | +5% (t=0.1) | +0.43 |
| BTC>+2% 后做多 | +0.38 | +0.58 | +10% (t=0.4) | +0.24 |
| BTC 符号多空 | +0.23 | +0.13 | +21% (t=0.2) | −0.37 |
| BTC 3 日动量 | −0.19 | −0.17 | −45% (t=−1.1) | −0.37 |
| BTC<−2% 后做多（逆向） | +0.44 | +0.51 | +6% (t=0.1) | +0.30 |

**每一条规则的毛收益都低于买入持有的 +1.45**，且所有 Alpha 的 t 值都在 ±1.1 以内——没有一条统计上可区分于零。SOL（2024-03→2026-08，B&H −0.24）同构：追涨 −0.50~+0.12，逆向 +0.44（t=1.0）。

### 3.4 周频与月度"轮动"检验

- 周频 CCF lag+1 周：HYPE −0.04、SOL −0.01、ETH +0.06——全不显著。**"BTC 先涨一周、山寨下周补涨"在近两年不存在。**
- 21 天轮动回归（过去 21 天 BTC → 未来 21 天山寨相对 BTC）：HYPE +0.69（t=2.3，BTC 强月后 HYPE 相对跑赢 +14%）；**SOL −0.28（t=−3.2，BTC 强月后 SOL 相对跑输 −6%）**。同期两币方向相反 → 这是各自叙事（HYPE 是 2025-26 的结构性赢家）而非 BTC 先导规律。
- 长样本（2020-04 起）里轮动为正（+0.77，t=2.6，Q4 +23%）、周频 lag+1 也显著（+0.17，t=3.1）——**旧时代真实存在的传导，2024-26 已消失**。

HYPE 与 BTC 的相关只有 SOL/ETH 的一半左右，现值 0.52：BTC 只解释其方差的 ~26%，其余是自身因素（CFTC/合规消息 2026-01-27 单日 +21%、二月解锁 ~9.9M 枚、HyperEVM、回购；2026 年 6 月在 BTC 下跌中因 ETF 叙事逆势入市值前十；8 月 19-21 日因 Trump/CFTC 表态再创新高——见文末来源）。

### 3.6 LIT（Lighter）：无法做统计检验，锚点显示与 BTC 高度脱节

可得数据只有 7 个日度价格 + 6 个锚点：

| 阶段 | LIT | BTC 同期 |
|---|---|---|
| 2025-12-30 TGE → 2026-03-31 | **−81%**（$4.04 → $0.78） | −22% |
| 2026-03-31 → 05-18 | +11% | +13% |
| 2026-05-18 → 05-24 | **+41%** | −0.4% |
| 2026-05-24 → 08-10 | **+88%** | **−15%** |

## 4. 稳健性与告诫

### 4.1 补全数据带来的新检验

- **拼接质量**：补全序列与原 CM 序列有 87 天重叠，对齐后相关 **0.994**，拼接点（2026-02-26）无跳变。
- **口径敏感性是本文最重要的稳健性发现**：BTC 大跌后的"逆向反弹"在原 CM 配对下 t=2.55，换成 API 面板的 BTC 腿（同一时期、同一份 HYPE 数据）就掉到 t=0.91。原因是两个 BTC 价格源对"当天跌了 3%"的判定不完全一致（事件日 45 天 vs 37 天）。**真信号不该这么脆弱** —— 详见 §0 和 §3.2。
- **web 锚点的误差**：真实日线到位后，可以校对此前用 web 检索拼出的锚点，误差最大到 **+14.8%**（2026-06-16 锚点 $76.77，实际 $66.89；"ATH" 实为 8/23 的 $79.49）。锚点保留在 `data/hype_anchor_points.csv` 供追溯，但**所有统计均已改用真实日线**，此前基于锚点的"区间相关 ≈ +0.30"粗估作废。

### 4.2 近三个月"BTC 领先一天"的假象（重要）

补全数据后，单看缺口窗口（2026-05-24..08-23, n=92）会看到一个与主结论相反的信号：lag+1 相关 **+0.29（t=2.7）**、Granger p=0.006、预测回归 btc(t) 系数 +0.78（t=2.9），对应回测 Sharpe 高达 3.9。**这是采样假象，不可交易**，四项诊断：

1. **同源对照**：同期 SOL（+0.39, t=3.7）与 ETH（+0.36, t=3.4）出现**更强**的同一现象。二者与 BTC 出自同一快照文件、时间戳绝对一致，排除跨源错位。
2. **BTC 自身自相关异常**：缺口期 API 面板 BTC 日收益的 ρ(1) = **+0.425**，而同一数据源此前 809 天为 −0.091、独立的 CM 源同期为 −0.058。日线 BTC 不可能突然获得 0.43 的自相关（那将是巨大且早被套利的异象）。
3. **机械关系吻合**：lag+1 ≈ ρ_btc(1) × 同期相关。预测值 SOL 0.355 / ETH 0.366 / HYPE 0.205，实测 0.388 / 0.357 / 0.287——几乎完全对上，说明"领先"只是 BTC 自身自相关经同期 Beta 的传导。
4. **控制同期腿后消失**：回归 `alt[t+1] ~ btc[t+1] + btc[t] + alt[t]`，btc[t] 的系数在 SOL（t=−1.4）与 HYPE（t=+0.7）均不显著。
5. **方差比佐证**：缺口期 VR(2)=1.43（正常应 ≈1，此前 809 天为 0.91），是非同步采样的典型特征——npm 快照的抓取时点在近三个月发生漂移。

结论：**近期"BTC 领先一天"是数据采样产物，不是市场规律。** 分析脚本现已内置 `sampling_quality`（ρ(1) 与 VR(2)）与 `lag1_mechanical_benchmark`（ρ×corr0 基准）两项自动诊断，任何 lag+1 结果都会附带这两个对照。

### 4.3 一般性告诫

- HYPE 在 2026-02-25 之前的收益经由 CM 市值列反推（方法验证见 §1），已剔除 1 个确认的流通量修订日（2025-08-28）。
- 本文检验了 6 条规则 × 多个配对 × 多个窗口，存在多重检验问题——不应把任何 |t|<3 的孤立结果当成实盘依据。
- 分钟级的 BTC→山寨领先在文献与实务中存在但衰减极快（秒-分钟级、由高频做市与套利收敛），日线数据无法检验，也不构成人工可执行的策略。
- **数据管道的历史问题**（保留备查）：本分析环境出口网络为白名单制，40+ 个行情端点全部被 403 拦截；Coin Metrics 的 GitHub 仓库只是镜像，其每日 CI 实际推送到 GitLab 私有库 `coinmetrics/data-delivery/data`，镜像同步在 2026-05-24 后中断；npm 的 `@fawazahmed0/currency-api` 虽每日更新但币种表冻结于 2024 年初，无 hype/lit。HYPE 缺口最终由用户在无网络限制的机器上运行 `fetch_hype_extension.py` 补齐。
- 本文为历史统计描述，不构成投资建议。

## 5. 实践含义

1. 想要"BTC 涨了再上车山寨吃时间差"——**这个时间差在日线级别不存在**，2021 年那种隔日/隔周补涨已被套利掉。
2. **没有"退而求其次"的方向。**初版曾提示大跌后的短线逆向或许勉强可用；补全数据后该效应不成立（换一个同样合理的 BTC 价格源，同一时期即从 t=2.5 掉到 t=0.9）。追涨与抄底两个方向都不构成信号。
3. 持有 SOL/ETH 相对 BTC 的差异主要是**不对称 Beta**（下行 1.4 倍，口径稳健）；持有 HYPE/LIT 则主要暴露于**其自身基本面/筹码叙事**（收入回购、解锁、ETF/合规进展、空投消化），应当按各自基本面而非 BTC 图形来定仓位与时点。
4. **看到高 Sharpe 先查数据。**本次补全后，单看缺口窗口曾给出 Sharpe 3.9、年化 Alpha +193% 的"信号"，实为 npm 快照采样漂移造成的假象（§4.2）。任何 lag+1 结论都应先对照 `ρ_btc(1) × corr0` 的机械基准，并控制同期腿 `btc[t+1]`——脚本已内置这两项诊断。
